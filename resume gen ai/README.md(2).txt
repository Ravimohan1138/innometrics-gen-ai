# AI Resume Screening System with LangChain

## Objective
This project builds an AI-powered Resume Screening System using LangChain and HuggingFace.

## Features
- Skill Extraction
- Resume Matching
- Candidate Scoring
- Explainable AI Output
- LangSmith Tracing

## Technologies Used
- Python
- LangChain
- HuggingFace
- LangSmith

## Pipeline Flow
Resume → Extract → Match → Score → Explain

- Strong Candidate
- Average Candidate
- Weak Candidate
